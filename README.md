# SGD — Sistema de Gestão dos Desbravadores

Plataforma de gestão para clubes de Desbravadores: catálogo oficial
(ideais, classes e especialidades), cadastro de clubes e acompanhamento
da progressão dos desbravadores.

## Stack

- **Back:** Java 25 + Spring Boot 4 (Web, Data JPA, Validation, Security)
- **Front:** Angular v21+ (standalone, signals) + Angular Material
- **Banco:** PostgreSQL, migrations com Flyway

## Estrutura

    sgd/
    ├── api/   Backend Spring Boot
    └── web/   Frontend Angular
